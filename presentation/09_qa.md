## Sekcja pytań

Pytanie | Sugerowana odpowiedź |
|---|---|
| *Dlaczego SCD Type 2 a nie Type 1?* | Chcemy historię zmian — np. jeśli ETF zmieni kategorię, stare fakty nadal powinny wskazywać na starą wersję wymiaru |
| *Co się stanie gdy API zwróci błąd rate-limit?* | `RateLimitError` łapany gracefully — pipeline przetwarza symbole załadowane do momentu limitu, nie crasha |
| *Jak działa delta danych?* | `etl_watermark` przechowuje `last_loaded_date` per symbol; pobieramy tylko rekordy nowsze niż watermark |
| *Czym się różni raw od marts?* | `raw` to surowe dane z API bez transformacji; `marts` to wymiary + fakty po joinach z obliczonymi miarami |
| *Dlaczego Airflow a nie cron?* | Retry, wizualizacja wykonania, dependency management między taskami, monitorowanie |
| *Co to jest CUBE() i po co?* | Operator SQL generujący wszystkie kombinacje GROUP BY — odpowiednik kostki OLAP bez dodatkowego narzędzia |
| *Czy dane są aktualne?* | Tak — Airflow triggeruje pipeline każdy dzień roboczy o 22:00 UTC, po zamknięciu sesji NYSE |
| *Co byś dodał gdyby to był projekt produkcyjny?* | Alerty e-mail na failure, więcej źródeł (np. dane makroekonomiczne z FRED API), SLA w Airflow |
